# Design & Visuals

## Theme
- **Color Scheme**: Deep darks offset by vibrant neon accents, evoking a high-tech/arc-reactor futuristic aesthetic.
  - Backgrounds: Deep blues/blacks (`#00060a`, `#010d14`).
  - Primary Accents: Cyan (`#00d4ff`) by default, though it is fully user-configurable via a Hue color wheel.
  - Success/Valid: Green (`#00ff88`).
  - Alert/Error: Red (`#ff3355`).

## Typography
- **Primary Font**: `Courier New` (to emphasize the terminal/console aesthetic).
- **Headings**: Capitalized, bolded with small bullet points (e.g. `◈ SYS MONITOR`).

## Interactive Elements
- **HUD (Heads Up Display)**: Features animated, concentric pulsing rings around a central node (or user-defined face image). The rings scale and pulse dynamically in tandem with microphone input volume.
- **Buttons**: Ghosted backgrounds with solid colored borders, turning solid upon hover or active states.
